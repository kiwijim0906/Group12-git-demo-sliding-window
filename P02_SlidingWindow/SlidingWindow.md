# P02：滑動視窗最大子陣列和 (Sliding Window Maximum Subarray Sum)

## 題目敘述
給定一個長度為 `n` 的整數陣列 `a[1..n]`，以及一個正整數 `k`，請找出所有「連續 k 個元素」組成的子陣列中，總和最大的那一個，並輸出這個最大總和。

## 輸入格式
第一行：兩個以空白分隔的正整數 `n k`（`1 <= k <= n <= 100000`）
第二行：`n` 個以空白分隔的整數 `a[1], a[2], ..., a[n]`（`-10000 <= a[i] <= 10000`）

## 輸出格式
一個整數：長度為 `k` 的連續子陣列中，總和的最大值（結尾需換行）。

## 範例
輸入：
6 3 
2 1 5 1 3 2

輸出：
9

說明：長度為 3 的子陣列共有 `[2,1,5]=8`、`[1,5,1]=7`、`[5,1,3]=9`、`[1,3,2]=6` 四種，最大值是 9。
