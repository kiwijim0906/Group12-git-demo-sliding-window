# P02：滑動視窗最大子陣列和（Sliding Window Maximum Subarray Sum）

## 題目敘述

給定一個長度為 `n` 的整數陣列 `a[1..n]` 與一個正整數 `k`，請找出所有長度恰為 `k` 的**連續子陣列**中，元素總和最大的值。

換言之，對每個起點 `i`（`1 <= i <= n - k + 1`），計算：

```text
a[i] + a[i + 1] + ... + a[i + k - 1]
```

並輸出其中的最大值。

## 輸入格式

輸入共兩行：

- 第一行包含兩個以空白分隔的正整數 `n` 與 `k`。
- 第二行包含 `n` 個以空白分隔的整數 `a[1], a[2], ..., a[n]`。

限制如下：

- `1 <= k <= n <= 100000`
- `-10000 <= a[i] <= 10000`

## 輸出格式

輸出一個整數，表示所有長度為 `k` 的連續子陣列中，元素總和的最大值。輸出結尾應包含換行字元。

## 範例輸入

```text
6 3
2 1 5 1 3 2
```

## 範例輸出

```text
9
```

## 範例說明

長度為 `3` 的連續子陣列及其總和如下：

| 子陣列 | 總和 |
| --- | ---: |
| `[2, 1, 5]` | 8 |
| `[1, 5, 1]` | 7 |
| `[5, 1, 3]` | 9 |
| `[1, 3, 2]` | 6 |

其中最大總和為 `9`，因此輸出 `9`。
